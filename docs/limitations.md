# Ограничения

## Данные

- Нет `order_id`, количества, времени суток, статусов заказов, отмен и возвратов. `purchase_days_90d` — число
  дней с покупками, не число заказов. Отсутствие возвратов в данных не означает, что их не было.
- Одинаковые строки (все пять полей) сохранены как отдельные единицы; если часть из них — технические дубли,
  денежные признаки и `rows_*` завышены. Различить по источнику нельзя.
- Шкала `price` не задокументирована (значения 1.7e-5 … 0.59); все суммы — в предоставленной шкале, не в
  валюте и не выручка/прибыль.
- Смысл `sales_channel_id` (1/2) не раскрыт; доля канала 2 по месяцам меняется (см.
  `reports/data/figures/monthly_channel_share.png`), в том числе в 2020 году. Модель обучена на смеси периодов.
- `target = 0` — отсутствие наблюдаемой покупки H&M в этом наборе за 30 дней, не отток и не отсутствие покупок
  вообще.
- Поля `customers.csv` — снимок без даты актуальности; не используются.

## Валидация

- Один final test (2020-08-24) и три development-fold за апрель–июль 2020. Разброс по fold приведён, но
  устойчивость на других сезонах не доказана.
- Bootstrap-интервалы учитывают выборочную неопределённость клиентов одного периода, не временной сдвиг.
- Early stopping CatBoost использует validation текущего fold (требование задания), поэтому dev-оценки CatBoost
  слегка оптимистичны относительно LR. На final test число деревьев фиксировано заранее.
- Выбор лучшей конфигурации внутри кандидата по тем же fold даёт небольшой оптимистичный сдвиг mean AP
  (4 конфигурации CatBoost против 3 значений C).
- Правило `near_best` с допуском 0.005 AP — инженерное правило, не тест эквивалентности.
- Калибровка оценена на одном срезе (2020-07-25); её качество на других периодах не проверялось.

## Интерпретация

- Модель прогнозирует наблюдаемую покупку, а не эффект контакта. Uplift, ROI, рост продаж и причинный эффект
  CRM-воздействия не измерялись. Бюджет top 5% — проектное допущение.
- Модель не готова к внедрению: нет мониторинга сдвига, нет повторной валидации на новых периодах, нет
  согласованного бизнес-порога.

## Незапущенные этапы (not_run)

| Этап | Статус | Причина / команда |
|---|---|---|
| GPU-обучение CatBoost | not_run | CPU-путь достаточен; `resources.task_type: GPU` в конфигурации — не проверялось |
| Горизонты 60/90 дней | not_run | требует отдельной временной схемы; не выполнялось |
| Delivery-модель (переобучение на всех созревших данных после теста) | not_run | не требовалась для отчёта; должна получить отдельную версию и калибровку |
| class_weight / oversampling | not_run | меняют интерпретацию вероятностей; по умолчанию не используются |
| Категории товаров в признаках | not_run | JOIN с `articles.csv` проверен, но признаки по товарам не строились |
